# Chat Support Dashboard

A polished chat support dashboard built with **Next.js**, **TypeScript**, and **shadcn/ui-inspired components**.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Reusable UI primitives (Button, Card, Badge)
- Lucide icons
